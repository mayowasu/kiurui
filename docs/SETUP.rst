#####
Setup
#####

Before you begin
================

Make sure you have a **supported version of Python installed (>3.11)**, and that you're working in the directory where kiurui is located.

Getting started
===============

You'll need a `terminal emulator <https://en.wikipedia.org/wiki/Terminal_emulator>`_ to run kiurui. Once you have one open and you're in the directory where kiurui is located, run:

.. code-block:: bash

    python3 kiurui.py
